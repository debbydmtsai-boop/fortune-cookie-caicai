《幸運餅乾》V1｜GitHub Pages 上傳與驗收

上傳方式
1. 將本 ZIP 解壓縮。
2. 將 index.html、assets、audio、data 和此說明檔一起上傳至 GitHub 儲存庫根目錄。
3. 保持資料夾與檔名不變，啟用 GitHub Pages 後從正式 HTTPS 網址測試。
4. 不能只上傳 index.html；本作品需要影片、圖片、音效及籤文 JSON。
